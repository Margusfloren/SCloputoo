# V1 KPI-d

V1 sisaldab lõputöö kaitsmiseks vajalikku põhitaseme juhtimisinfot.

## Müük
- Sales Budget, t
- Sales Actual, t
- Budget vs Actual, t
- Budget Achievement, %

## Tootmine
- Production Plan, t
- Production Actual, t
- Production Plan Achievement, %

## Tarnekindlus
- OTIF, %

V1 eesmärk on näidata, kas müük ja tootmine liiguvad plaani järgi ning kas klienditellimused täidetakse õigel ajal ja täies mahus.
